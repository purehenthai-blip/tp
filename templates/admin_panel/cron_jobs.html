How Cron Jobs Work

Tasks run automatically via Celery Beat. Start it with:

celery -A toasterpants beat -l info --scheduler django_celery_beat.schedulers:DatabaseScheduler

Worker process:

celery -A toasterpants worker -l info

Redis must be running for Celery to work. See README for setup instructions.
